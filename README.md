# E-Catalog — Ulgurji Elektron Katalog (Wholesale E-Catalog)

Zamonaviy **Material Design 3** asosida yaratilgan ulgurji savdo elektron katalogi.

## Xususiyatlari:
- 📱 **Mobile-First & Material Design 3:** Mobil qurilmalarda tezkor va silliq ishlash uchun optimallashtirilgan pastki navigatsiya paneli (Bottom Navigation Bar) va moslashuvchan interfeys.
- 🌐 **Ikki tilli (Bilingual):** O‘zbekcha va Ruscha to‘liq qo‘llab-quvvatlash.
- 💰 **Ochiq ulgurji narxlar:** 1 dona/pochka narxi va 1 blok/korobka narxi ochiq ko‘rsatiladi.
- 📦 **Ombor qoldig‘i monitoringi:** Haqiqiy mavjud tovarlar soni va partiyalar hisobi.
- ✈️ **Telegram & Ulashish:** Bir bosishda Telegram orqali so‘rov yuborish va mahsulotni boshqa ilovalarda (Telegram, WhatsApp, Facebook, Web Share API) ulashish.
- 📊 **Prays-list & Eksport:** Excel (CSV) yuklab olish va PDF/Chop etish rejimi.
- ⚙️ **Admin boshqaruv paneli:** Tezkor narx/qoldiq yangilash, tovarlar va kategoriyalarni boshqarish, brend va kontakt ma'lumotlarini sozlash.

## Texnologiyalar:
- **Framework:** Next.js 15 (App Router)
- **Til:** TypeScript
- **Stilizatsiya:** Tailwind CSS, Material Symbols Rounded, Material Web M3
- **Ma'lumotlar bazasi:** Mahalliy JSON / API integratsiyaga tayyor arxitektura

## O‘rnatish va ishga tushirish:
```bash
# Kutubxonalarni o‘rnatish
npm install

# Dasturchi rejimida ishga tushirish
npm run dev

# Ishlab chiqarish (Production) uchun build qilish
npm run build
npm run start
```
